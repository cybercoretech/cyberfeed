# 🔒 Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability within Cyberfeed, please report it privately via GitHub security advisories or by contacting the maintainers directly.
