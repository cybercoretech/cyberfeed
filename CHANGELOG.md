# 📝 Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-10-27
* **Added**: Tabbed navigation by feed family.
* **Added**: Multi-theme support (`Cyberpunk`, `Dracula`, `Nord`).
* **Added**: Syntax highlighting for code blocks in articles and quick previews.
* **Added**: Robust synchronous startup fetching and non-destructive SQLite migrations.

## [0.1.0] - 2026-10-25
* Initial prototype with basic RSS/Atom parsing, Ratatui list view, and browser integration.
