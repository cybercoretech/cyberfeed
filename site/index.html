📦 Quick Installation

Clone the repository, build with release optimizations, and launch straight into your feeds.

git clone https://github.com/cybercoretech/cyberfeed.git && cd cyberfeed && cargo build --release

⚙️ Configuration

Configure feeds, refresh intervals, and themes in ~/.config/cyberfeed/config.yaml.

theme: cyberpunk # Options: 312+ themes via popup [t]
Core Features Optimized for Power Users

⚡ Asynchronous Polling

Powered by `tokio` and `reqwest` with custom User-Agent headers and non-blocking background feed synchronization.

📂 Tabbed Feed Families

Automatically separates and groups articles by source into distinct tabbed navigation views with aggregate "All" feeds.

🎨 312+ Theme Matrix

Switch instantly between 312+ Cybercore theme palettes using the scrollable modal popup (`t` key).

📖 Syntax-Highlighted Reader

Clean markdown parsing via `pulldown-cmark` with code blocks and headers dynamically styled to active theme palettes.

📋 Clipboard & Browser

Instantly copy article links to the system clipboard (`y`) or launch them in your default browser (`o` / `b`).

🗄️ Robust SQLite Storage

Non-destructive schema migrations and reliable local article persistence powered by bundled `rusqlite`.
